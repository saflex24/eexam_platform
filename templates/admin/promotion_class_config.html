Configure Class Promotion Order

Set the promotion level for each class, mark terminal (graduating) classes, and optionally link each class to its specific next class.

How it works: Set Level in ascending order (e.g. JSS1=1, JSS2=2, JSS3=3, SS1=4, SS2=5, SS3=6). During bulk promotion, students move from their class to the class with Level + 1 — or to the explicitly linked Next Class. Mark the final class (e.g. SS3) as Terminal — students there will be graduated, not promoted.
